# BnbEmu

PopTag (Crazy Arcade / 爆爆王 / 泡泡堂) Server Emulator, for North America client.

美服泡泡堂服务端模拟器。

⚠ 代码大部分由AI编写，并经过人工审查。

## Usage 

需要 JDK 17+ 与 Maven 3.9+。在项目根目录执行：

Requires JDK 17+ and Maven 3.9+. Run under project directory:

```powershell
mvn compile exec:java
```

在Release页面最老的条目下载客户端。输入任意账号密码登录。

Download the client from the oldest entry on the Releases page. Enter any username and password to log in.

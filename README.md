# BnbEmu

PopTag (Crazy Arcade / 爆爆王 / 泡泡堂) Server Emulator, for North America client.

美服泡泡堂服务端模拟器。

⚠ AI代码警告，人工含量极低。

## Usage 

需要 JDK 17+ 与 Maven 3.9+。在项目根目录执行：

```powershell
mvn compile exec:java
```

在Release页面最老的条目下载客户端。输入任意账号密码登录。
